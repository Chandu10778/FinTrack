# 💰 FinTrack - Personal Finance Tracker

FinTrack is a simple and user-friendly personal finance tracking web application built using HTML, CSS, and JavaScript.

It helps users manage their income and expenses, monitor budgets, and understand their spending habits through an easy-to-use dashboard.

## 🚀 Features

- 📊 Financial dashboard
- 💰 Track income and expenses
- 🧾 Add and manage transactions
- 🔍 Search and filter transactions
- 📅 View transactions by month
- 🎯 Create and manage budgets
- 📈 Income vs. expense charts
- 💵 Balance and spending summary
- 📱 Responsive user interface
- 💾 Client-side data storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Chart.js
